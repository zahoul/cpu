Document Structure Example

=== RV32I Base Integer Instruction Set This section describes the RV32I base integer instruction set. ==== Programmers' Model for Base Integer ISA For RV32I, the 32 `x` registers are each 32 bits wide, i.e., XLEN=32. Register `x0` is hardwired with all bits equal to 0. ==== Integer Register-Immediate Instructions ADDI adds the sign-extended 12-bit immediate to register rs1. Arithmetic overflow is ignored and the result is simply the low XLEN bits.
